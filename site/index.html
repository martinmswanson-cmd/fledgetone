A music studio that runs in your browser.

Arrange songs on a timeline, write in a piano roll, mix with real effects and export finished audio. Score to picture and make music for games that reacts to play. No install, no account, and nothing you make leaves your computer.

Fledgetone is laid out more like a video editor than a classic music program, and it's built most of all for people who make music for games and video, and for beginners who want something that sounds good on day one. Open a starter song, press Space, and start changing things.

FeaturesEverything a song needs, in one tab

01 · Write

A piano roll with helping hands

Write notes in a key, drop in chord progressions, then let the smart tools add an accompaniment, a bass line, a drummer and fills. Arpeggiate, strum, humanize, or let a formula write a pattern. Tick Notation to read the clip as sheet music, print it, or save MusicXML for MuseScore, Sibelius and Dorico.

  • Scales, chords, arpeggios, swing per clip
  • Mod wheel dynamics, vibrato, legato and swells
  • MIDI keyboard input, takes and microphone recording

02 · Mix

A mixer that sounds finished

Every track gets its own effects rack, sends to shared reverb and delay, and automation lanes. Group tracks into buses, sidechain anything, and finish on a master chain with multiband compression, stereo width and reverb from recorded rooms.

  • 644 built-in plugins (Airwindows, MDA, Open303, Mutable Instruments, Faust) compiled to WebAssembly
  • Load more from the web as Web Audio Modules
  • Freeze heavy tracks to audio to save CPU

03 · Game

Music that reacts to play

Each section of a song becomes a game state that loops on its own. An Intensity slider builds stem groups up and down, transitions carry you between states, and stingers land in key. Audition it like the game would, then export.

  • Game kits with players for the web, Unity and Godot
  • Ready-made packages for FMOD Studio and Wwise
  • A sound effects maker for the rest of your game's audio

Score to picture

Load a reference video, read timecode at any frame rate, mark hit points and let the tempo finder land the music on them. Cut 6 to 90-second versions and export the music onto the video.

198 instruments

Wobble, growl, Reese and 808 basses, supersaws and chiptune, a Synth Designer, drum kits, and recorded pianos, guitars, strings, brass, winds and choirs from free sample libraries.

Export anything

WAV, MP3 and Ogg, separate stems, MP4 video, seamless loops for games, sheet music. Or share a link with the whole song packed inside it.

Learn as you go

A one-minute tour, hands-on tutorials from your first song to game music, a full guide inside the app, and search (Ctrl+K) that finds every tool, setting and instrument.

Bring your own sounds

Record from a microphone, drop in audio files, chop vocals in the Slicer, and build instruments and drum racks from your own recordings.

Private by design

There's no server and no sign-in. Songs autosave in your browser and save to .fledgetone.json files. Instruments download once, then work offline.

The code is meant to be picked up by someone new. Every file opens with a summary of what it is, an architecture guide walks through what happens when you edit, play, save and export, and the music logic is pure functions with unit tests.

Run it yourself · Node 22
$ git clone https://github.com/martinmswanson-cmd/fledgetone
$ cd fledgetone
$ npm install
$ npm run dev        # http://localhost:5173
$ npm test
$ npm run build:single # the whole app in one HTML file
